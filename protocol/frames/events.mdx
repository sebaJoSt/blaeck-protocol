# Events

An event channel reports occurrences drawn from a closed list declared up front. `ChannelIndex` and
`EventIndex` are positions in the `80` catalog. See
[Elements](../elements) for field details.

<Frame id="80" />

Every channel carries at least one `EventType`: the list is what an occurrence is resolved
against, and what a host needs to describe the channel at all, so a channel with none can neither
report nor be shown.

The device class is carried as written, like a signal's: the frame holds no list of what a
consumer will accept. A consumer that validates strictly and finds no match has nothing to
fall back on, so an unrecognised name costs the entity rather than the field.
