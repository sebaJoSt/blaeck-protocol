Signal Config carries how a signal is presented: unit, device class, icon, state class, display
precision, and the label to show in place of the name. Only signals that declare something appear,
so the frame may hold no entries at all; `SymbolID` gives each entry's signal.

`DisplayName` is the label a host shows in place of the name. Presentation only: the name stays
what the symbol list gives, what a logged column is called, and what any identity a host derives is
built from, so declaring one later moves nothing.

A device sends this catalog at startup with the others (see [Control](control)). The
[schema hash](../schema-hash) cannot stand in for it: the hash covers a signal's name and type, so
a unit or an icon that moved while the signals stayed put leaves it unchanged. Read entries against
whichever symbol list the host holds, `SymbolID` being a position in it.

`SignalMetaFlags` determines the entry's structure. Each optional field follows only if its bit is
set, in the order above.
